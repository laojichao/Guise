# Guise

一个 Android Xposed 模块，用于修改设备参数伪装。

## 简介

Guise 是一个 Xposed 模块，允许你为 Android 设备上的应用传递自定义的设备参数。你可以模拟不同的设备型号、品牌、系统版本等信息。

## 功能特性

- 设备信息伪装（型号、品牌、制造商等）
- 系统参数修改
- 应用级别的独立配置
- 基于 Jetpack Compose 的现代 UI

## 环境要求

- Android 10+ (minSdk 29)
- 已安装 Xposed 框架（LSPosed、EdXposed 等）
